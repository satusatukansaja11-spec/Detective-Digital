# Paket laptop Cyber Detective

[Unduh paket RAR Tahap 1–7](https://github.com/satusatukansaja11-spec/Detective-Digital/raw/refs/heads/main/downloads/Cyber-Detective-Laptop-Tahap-1-7.rar)

Ukuran: 124.705 byte (sekitar 122 KiB).

1. Unduh dan ekstrak seluruh arsip memakai WinRAR atau 7-Zip.
2. Baca `MULAI-DI-SINI.txt` dalam folder hasil ekstraksi.
3. Untuk mode lokal Windows, pasang Python 3 lalu jalankan `JALANKAN-LOKAL-WINDOWS.bat`.
4. Untuk PHP–MySQL dan dashboard guru, ikuti panduan pada `APLIKASI-LENGKAP/docs/backend.md`.

Paket berisi mode lokal dan kode aplikasi lengkap beserta panduan. Tidak menyertakan akun guru siap pakai, kata sandi, data siswa, volume database, atau riwayat `.git`.

`SHA256SUMS.txt` dapat dipakai untuk memeriksa keutuhan arsip.
